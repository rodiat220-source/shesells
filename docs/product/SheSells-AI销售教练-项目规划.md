## 一、项目定位

### 1.1 一句话定位

**SheSells 是一个 AI 销售教练 Agent**，不是工具，是教练——它主动追问、主动喊停、主动对比，帮 BA 通过实战演练学会"懂顾客"，把销冠能力变成可复制的组织能力。

### 1.2 为什么是 Agent 而不是 SaaS

| 维度 | SaaS 产品 | Agent 方案 |
|------|----------|-----------|
| 体验 | 打开网页 → 点按钮 → 对话 | **直接对话，自然交互** |
| 价值 | 练习工具 | **智能教练，主动引导** |
| 页面 | 重前端，3 个页面 | **1 个对话界面** |
| 差异化 | 工具 | **Agent：有状态、有判断、有主动行为** |

**SheSells 不是给 BA 用的工具，是陪 BA 练习的教练。** 教练不会等你点按钮，教练会主动说"停一下，你这里漏了"。

### 1.3 Agent 的 3 个主动行为

这是"不是套壳"的核心——ChatGPT 只会回应，SheSells 会主动行动：

1. **主动追问**：BA 回复太简略时，Agent 不急着推进，而是说：
   > "你再想想，她刚说怕刺痛，你觉得她真正担心的是什么？"

2. **主动喊停**：BA 连续犯错时，Agent 暂停对话，弹出反馈：
   > "停一下——你已经连续 2 次没回应她的顾虑了，试试先共情再推荐。"

3. **主动对比**：对话结束后，Agent 不只是出报告，而是在对话流里说：
   > "你刚才在第 3 轮错过了一个关键信号，来看销冠是怎么处理的——"
   > 然后直接在对话里播放销冠版回复。

### 1.4 为什么是"她"卖（SheSells）

- 80% 的美妆 BA 是女性，但培训体系是男性逻辑：背话术、追KPI、逼单。
- 女性消费者要的不是"被推销"，是"被理解"。最好的销售不是最会说的，是最会听的。
- **SheSells 教的不是话术，是"懂她"的能力。**

### 1.5 愿景阶梯

```
AI 美妆销售教练 Agent  →  零售全品类陪练  →  企业级培训 OS  →  Sales Copilot
（黑客松 5 天）           （6-12 个月）        （1-2 年）         （长期）
```

## 二、市场机会

### 2.1 痛点

1. **BA 培训靠背话术，实战全靠悟**
   - 品牌培训是 PPT + 考试，考完就忘。没有真人顾客让你练手。
   - 新 BA 上岗前 3 个月转化率只有销冠的 1/3，但没人教她哪里做错了。

2. **销冠能力无法复制**
   - 销冠靠"感觉"，说不清自己为什么成交率高。
   - 区域督导巡店只能看结果，看不到过程。

3. **培训预算花了，效果不可衡量**
   - 品牌每年在 BA 培训上花费数十万/区域，但 ROI 无法量化。
   - 没有数据证明"培训后转化率提升了多少"。

### 2.2 机会大小

- 中国美妆零售市场规模超 4000 亿，线下渠道 BA 超 50 万人。
- 单品牌 BA 培训预算：10-50 万/年/区域，全国连锁品牌年培训费数百万。
- AI 陪练赛道在教育领域已有验证（如 Gong、Chorus），但**零售导购场景几乎空白**。

### 2.3 与现有赛道的差异

| 现有赛道 | 他们做什么 | SheSells 的差异 |
|---------|----------|----------------|
| 金融理财 AI | 帮用户选产品 | 我们帮品牌培养人 |
| 自我认知 AI | 给用户贴标签 | 我们教技能、练能力 |
| 决策帮手 AI | 帮用户做 A or B | 我们帮 BA 理解用户为什么纠结 |

## 四、Demo 聚焦：1 个场景做透

### 4.1 只做 1 个场景

**场景：敏感肌顾客想试早C晚A，但怕翻车**

为什么选这个：
- 每个女性评委都能共情——谁没在专柜被推销过？谁不怕烂脸？
- 痛点尖锐：BA 要同时处理"想变美"和"怕刺痛"的矛盾。
- Agent 能力展示空间大：追问、喊停、对比全考核。

### 4.2 Demo 核心体验（评委亲身参与）

```

│              SheSells Agent Demo 体验                   │
│                                                        │
│   评委扮演 BA ←→ SheSells Agent                        │
│   Agent 同时扮演两个角色：                               │
│   ├─ 顾客角色：犹豫、焦虑的敏感肌新手                    │
│   └─ 教练角色：在关键时刻主动介入                        │
│                                                        │
│   对话结束后：                                          │
│   Agent 在对话流里直接说：                               │
│   "你整体表现不错，但有 2 个关键时刻需要提升——            │
│    第 3 轮她说怕刺痛，你没回应；                          │
│    第 6 轮你直接推荐，没有先共情。                        │
│    来看销冠怎么处理同一个顾客——"                         │
│   然后在对话里播放销冠版关键轮次                          │
```

**全程只有一个对话界面**，所有评分、反馈、对比都在对话流里自然展开，不需要切页面。

### 4.3 Agent 3 个主动行为在 Demo 中的体现

| 主动行为 | Demo 中的触发时刻 |
|---------|-----------------|
| **主动追问** | BA 说"我推荐这款精华"就跳过需求探询时，Agent 问"等等，你还没了解她的皮肤状况，先问问她现在在用什么？" |
| **主动喊停** | BA 连续 2 次没回应顾客顾虑时，Agent 暂停："停——她说了 2 次怕刺痛，你都没接住，试试先共情" |
| **主动对比** | 对话结束后，Agent 在对话流里说"你第 3 轮错过了一个信号，来看销冠怎么处理——"然后播放销冠回复 |

### 4.4 Demo 不做什么

| 不做 | 原因 |
|------|------|
| 多场景切换 | 1 个场景做透比 3 个场景做浅强 10 倍 |
| 独立 Dashboard 页面 | Agent 在对话里直接说评分，不需要切页面 |
| 品牌知识库管理 | 硬编码 1 套 SKU 数据即可 |
| 用户注册/登录 | 跳过，Demo 直接进入 |
| 多顾客人格 | 只做 1 种：犹豫+焦虑的敏感肌新手 |

## 五、技术实现

### 5.1 架构（5 天能做到的版本）

```
┌───────────────────────────────────────────────────┐
│            SheSells Agent Demo 架构                 │
├───────────────────────────────────────────────────┤
│  前端（1 个对话界面）                                │
│  ├─ 对话流（消息气泡 + 教练介入高亮）                │
│  └─ 对话内嵌迷你雷达图 / 关键时刻标记               │
├───────────────────────────────────────────────────┤
│  Agent Core                                        │
│  ├─ 顾客模拟器（Customer Simulator）                │
│  │   └─ 人格 prompt + 需求/顾虑/购买信号生成        │
│  ├─ 评估教练合并器（EvaluatorCoach）                │
│  │   ├─ 5 维评分 + missed_concerns 检测             │
│  │   ├─ 追问触发器：检测 BA 回复质量过低             │
│  │   ├─ 喊停触发器：检测连续失误                     │
│  │   └─ 即时反馈 / 对比触发器：对话结束后启动        │
│  ├─ 销售状态机（Sales State Machine）               │
│  │   └─ 破冰→探询→异议→推荐→促单，每阶段有目标      │
│  └─ 教练消息生成器（CoachEngine，可选独立模块）     │
│      └─ 根据触发类型生成 coach 消息内容             │
├───────────────────────────────────────────────────┤
│  数据层                                            │
│  ├─ 硬编码 SKU 数据（5-10 个产品）                   │
│  ├─ 销冠预设回复（关键轮次）                         │
│  └─ 对话历史（内存/SQLite）                          │
├───────────────────────────────────────────────────┤
│  LLM                                              │
│  └─ 国产合规模型 API                                │
└───────────────────────────────────────────────────┘
```

### 5.2 3 个技术亮点

1. **销售状态机**：对话不是自由聊天，每轮都判断 BA 处于哪个阶段，阶段目标是否达成。
2. **教练主动行为**：Agent 不只是回应，而是基于状态机判断主动追问/喊停/对比——这是 Agent 和 ChatBot 的本质区别。
3. **关键时刻检测**：识别异议信号/购买信号，判断 BA 是否正确回应，未回应则标注并在对话结束后回放。

### 5.3 为什么不是套壳

| 维度 | ChatGPT + Prompt | SheSells Agent |
|------|-----------------|----------------|
| 交互 | 被动回应 | **主动追问、主动喊停、主动对比** |
| 结构 | 通用聊天 | **销售状态机**：每步有目标、有评估 |
| 反馈 | "你可以这样说" | "停——她说了 2 次怕刺痛，你都没接住" |
| 评估 | 没有评估 | **5 维评分 + 关键时刻标注**，对话内自然呈现 |
| 对比 | 无 | **对话内播放销冠回复**，不需切页面 |

**核心差异：ChatGPT 等你问，SheSells 主动教你。**

## 十、风险与对策

| 风险 | 对策 |
|------|------|
| 5 天做不完 | 只做 1 场景 + 1 顾客人格 + 1 个对话界面，砍掉所有独立页面 |

## 十一、评委 Q&A 预案

### Q1：这跟用 ChatGPT 扮演顾客有什么区别？

**A**：三个本质区别。第一，ChatGPT 是被动回应，SheSells 是主动教练——它会追问、会喊停、会主动对比。第二，ChatGPT 是自由聊天，SheSells 有销售状态机，每轮都在评估 BA 处于哪个阶段、目标是否达成。第三，ChatGPT 没有评估，SheSells 有 5 维评分和关键时刻标注，还会在对话里直接回放销冠怎么处理同一个顾客。

### Q2：评分准不准？

**A**：MVP 阶段用规则引擎 + LLM 评分，每个维度有明确标准。但 Demo 重点不是分数的绝对值，而是"关键时刻是否被捕捉到"——比如顾客说了"怕刺痛"但 BA 没回应，Agent 主动喊停，这个比分数更有说服力。

### Q3：品牌方真的会付费吗？

**A**：美妆品牌单 BA 年培训成本 ¥3000-8000，效果不可衡量。SheSells ¥200-500/月/人，低于现有成本，且效果可量化。先找 1-2 家品牌免费试点，用数据验证后再转付费。

### Q4：没有数据怎么冷启动？

**A**：3 个来源：① 品牌 SOP/话术手册 → 评分规则；② 销冠对话记录 → 关键时刻标注；③ 小红书/知乎真实咨询帖 → 顾客脚本。规则引擎 + LLM 推理就能跑通 MVP。

### Q5：为什么只做美妆？

**A**：美妆 BA 50 万+、培训痛感强、客单价高、场景标准化。跑通后直接迁移到母婴、服装等品类。

### Q6：合规风险？

**A**：功能型培训工具，不涉及情感陪伴、不收集消费者数据。练习数据归品牌，知识库隔离存储，LLM 境内调用。

### Q7：Agent 的主动行为会不会打扰 BA？

**A**：主动行为的触发条件是精心设计的——只有 BA 犯了明确的错误（如连续忽略顾客顾虑）才会触发。而且喊停不是批评，是引导："试试先共情再推荐"。这和好教练的教学方式一致——不是每句话都打断，是在关键转折点出手。

---

## 十二、关键原则

1. **Agent 不是工具，是教练**：会主动追问、主动喊停、主动对比——这是和 ChatBot 的本质区别。
2. **1 个场景做透**：5 天只做"敏感肌想试早C晚A"，不要贪多。
3. **1 个对话界面搞定一切**：评分、反馈、对比都在对话流里，不切页面。
4. **教技能，不教话术**：评分的是"懂她的能力"，不是"背稿的准确度"。
5. **主动行为是炸点**：评委亲身体验 Agent 喊停的那一刻，比任何雷达图都有冲击力。
6. **先跑通再打磨**：Day 3 必须端到端跑通，Day 4-5 才是打磨时间。
