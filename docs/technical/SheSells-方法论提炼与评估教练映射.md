# SheSells —— 方法论提炼与评估教练系统映射

> 文档日期：2026-07-13
> 来源：一堂「科学销售」六部课程（约40万字训练材料）
> 主讲人：李蕊（20年+销售管理实战经验）
> 用途：为 SheSells Agent 的评估引擎、教练决策、销冠对比提供理论基础

## 一、核心方法论全景

### 1.1 科学销售五步法（总框架）

```
用户卖点分层  →  销售过程拆解  →  业绩推进管理  →  销售激励  →  设计销售工具
（方向）        （路径）         （节奏）           （人和）      （事成）
```

#### 六大类典型错误（映射到 SheSells 评估维度）

| 错误类型 | SheSells 对应检测 | 评估维度 |
|----------|------------------|---------|
| 不懂科学销售 | 对话无结构，随机应对 | 流程合规度 |
| 缺用户卖点 | 不了解顾客需求就推荐 | 需求探询力 |
| 不拆销售过程 | 跳过关键阶段直接促单 | 阶段完整度 |
| 不抓销售过程 | 顾顾客信号无回应 | 信号捕获率 |
| 不懂激励 | N/A（训练模式） | — |
| 没有工具箱 | 无品牌知识支撑的推荐 | 专业知识度 |

---

### 1.2 销售过程拆解三步法（核心方法论，最重要）

**三步法全景：**

```
第一步：梳理用户决策
  ├── 确定用户产品（具象化用户是谁）
  └── 分析决策路径（四大决策类型）

第二步：划分销售阶段
  ├── 定义里程碑点（定性 + 定量分析）
  └── 梳理节点顺序（设计用户决策曲线）

第三步：设计销售动作
  ├── 做足动作加法
  ├── 匹配精准动作
  ├── 定义动作标准
  └── 配套销售工具
```

#### 核心金句（作为 Agent 教练话术的来源）

> "销售过程就是帮助客户降低每一个决策点成本的过程。"
> "但凡用户需要花时间的、花钱的、需要调动其他人的、可能对后续很多事情有影响的，这些都是可能的决策点。"

## 二、四大决策类型 → SheSells 状态机阶段映射

### 2.1 决策类型定义

| 决策类型 | 定义 | 美妆BA场景示例 |
|----------|------|--------------|
| **接触决策** | 用户愿不愿意接触你 | 顾客走进专柜、愿意跟你聊天、愿意让你试产品 |
| **购买决策** | 用户怎么决定要不要购买 | 顾客评估产品是否适合自己的肤质、价格是否合理 |
| **付款决策** | 用户完成打款动作 | 线下面销场景通常购买即成单，但可能有「回去想想」 |
| **履约决策** | 用户真的使用服务 | 顾客回家试用小样、按正确流程护肤并看到效果 |

### 2.2 映射到 SheSells 状态机

```
SheSells 销售状态机 v2（基于方法论重构）
─────────────────────────────────────────

STAGE 1: 破冰（接触决策）
├─ 里程碑：顾客愿意继续对话
├─ 检测指标：是否主动打招呼、是否建立眼神/语言联系
└─ BA 关键动作：打招呼 → 找共同话题 → 建立舒适感

STAGE 2: 探询（购买决策-需求识别）
├─ 里程碑：了解顾客皮肤状况、需求和顾虑
├─ 检测指标：是否询问肤质、是否询问护肤习惯、是否了解预算
└─ BA 关键动作：主动提问皮肤状况 → 了解在用什么 → 发现真正痛点

STAGE 3: 异议处理（购买决策-降低决策成本）
├─ 里程碑：顾客的顾虑得到有效回应
├─ 检测指标：是否识别并回应顾客的concern、是否做了共情
└─ BA 关键动作：先共情再解答 → 用专业知识打消顾虑 → 不应跳过

STAGE 4: 推荐（购买决策-选择方案）
├─ 里程碑：顾客认可推荐方案
├─ 检测指标：推荐是否基于探询结果、是否匹配肤质和需求
└─ BA 关键动作：基于探询结果推荐 → 说明为什么适合她 → 不盲目推荐最贵的

STAGE 5: 促单（付款决策）
├─ 里程碑：顾客决定购买/体验
├─ 检测指标：是否自然推进、是否无压力促单
└─ BA 关键动作：提供体验/试用机会 → 不强推强卖 → 给顾客安全感
```

### 2.3 里程碑点的判定标准（6条，源自方法论）

作为 Agent 判断当前阶段的关键依据：

| 编号 | 判定标准 | 美妆场景含义 |
|------|---------|------------|
| 1 | 从陌生到有联系 | 顾客愿意跟你聊天 |
| 2 | 确认关键信息 | 顾客说出自己的肤质/需求/顾虑 |
| 3 | 投入时间多 | 顾客愿意坐下来试用产品 |
| 4 | 真正要花钱 | 顾客询问价格、考虑是否购买 |
| 5 | 长远影响大 | 顾客担心产品长期效果（如早C晚A是否适合） |
| 6 | 牵涉其他人 | 顾客说"我得问问我朋友/家人" |

**里程碑点 = 用户决策成本高的点**（即 Agent 应该重点监控的阶段转折）

## 三、评估体系设计

### 3.1 五维评估模型（基于方法论提炼）

| 维度 | 方法论来源 | 检测内容 | 评分权重 |
|------|----------|---------|:---:|
| **需求探询力** | "用户卖点分层"（用户分析→匹配卖点） | BA是否主动了解顾客肤质、在用什么、预算、顾虑 | 30% |
| **共情倾听力** | "梳理用户决策"（从用户视角出发） | BA是否识别并回应情感信号、是否先共情再介绍产品 | 25% |
| **产品匹配度** | "卖点提炼四步法"（FAB/动力阻力触点） | 推荐是否基于探询结果、是否匹配肤质和需求、是否讲人话 | 20% |
| **异议处理力** | "动力阻力触点"（减少购买阻力） | 当顾客表达顾虑时，BA 是否正确回应而非跳过 | 15% |
| **阶段完整度** | "划分销售阶段"（里程碑推进） | 是否按正确顺序推进、是否跳过关键阶段 | 10% |

### 3.2 关键时刻（Key Moments）检测

Agent 需检测以下关键信号并标注：

| 信号类型 | 示例 | 方法论来源 |
|----------|------|----------|
| **购买信号** | 顾客说"这个适合我吗？"、"能试试吗？"、"多少钱？" | 购买决策分析 |
| **异议信号** | 顾客说"我怕刺痛"、"太贵了"、"之前用过不行" | 用户决策卡点分析 |
| **信任信号** | 顾客主动说出自己的护肤困扰、愿意让BA看皮肤 | 接触决策推进 |
| **流失信号** | 顾客沉默、敷衍回答、看手机、想离开 | 未回应的决策成本 |

### 3.3 评估标准（好销售 vs 差销售的关键区分）

源自方法论中 "好的销售和差的销售的差距"：

| 评估点 | 差的表现 | 好的表现 | 评估方法 |
|--------|---------|---------|---------|
| 阶段推进 | 跳过探询直接推荐 | 每个阶段有明确的收尾动作 | 状态机顺序检测 |
| 信号回应 | 顾客说怕刺痛，BA说"没事的" | 先共情："你担心过敏对不对？那我们先做过敏测试" | missed_concerns 检测 |
| 推荐依据 | 推荐最贵的/最好卖的 | 基于探询结果推荐：你的肤质最适合这个 | 探询→推荐吻合度检测 |
| 促单方式 | 硬推"今天买有优惠" | 自然推进"你可以先试试小样感受一下" | 促单方式判定 |
| 专业表达 | "这个很好的" | 讲人话，说清楚为什么适合她的肤质 | 话术质量评估 |

## 四、教练决策规则

### 4.1 主动追问触发规则

**触发条件：BA 回复质量过低（源自"做足动作加法"）**

| 规则 | 检测逻辑 | Coach 消息模板 |
|------|---------|---------------|
| R1: 跳过探询 | 状态机检测 BA 未经过 STAGE 2 直接进入 STAGE 4 | "等等，你还没了解她的皮肤状况，先问问她现在在用什么？" |
| R2: 回复过简 | BA 回复 < 20字 且 不包含提问 | "你再想想，她刚说怕刺痛，你觉得她真正担心的是什么？" |
| R3: 未追问信号 | 顾客给出购买/异议/信任信号，BA 未回应就切换话题 | "她刚提到了{信号关键词}，这是一个重要的信息，你该追问一下" |

### 4.2 主动喊停触发规则

**触发条件：BA 连续犯错（源自"里程碑点监控"）**

| 规则 | 检测逻辑 | Coach 消息模板 |
|------|---------|---------------|
| S1: 连续忽略顾虑 | 连续 2 轮 BA 未回应顾客的顾虑信号 | "停一下——她已经说了 2 次怕刺痛，你都没接住。试试先共情再推荐。比如可以说：'我理解你担心烂脸，其实早C晚A可以从低浓度开始建立耐受'。" |
| S2: 跳过关键阶段 | BA 跳过 2 个关键阶段直接促单 | "停——你跳过了需求探询和产品匹配，直接推荐是不对的。先了解她的肤质。" |
| S3: 错误回应 | BA 用否定/忽视方式回应顧客顾虑 | "注意——你说'没事的'等于在否定她的感受。正确的做法是先认可：'你说的对，敏感肌确实要小心'，再解释为什么适合。" |

### 4.3 教练消息设计原则（源自激励50策略）

教练消息的语调和方式，借鉴销售激励方法论中的教练原则：

| 原则 | 方法论来源 | 含义 |
|------|----------|------|
| **先认可再纠正** | "及时鼓励"（策略39） | 指出问题前先说 BA 哪里做得好 |
| **提供方向而非答案** | "策略制定"（业绩推进第二步） | 给 BA 思考方向，不给标准答案 |
| **具体可执行** | "定义动作标准"（8322 原则） | 反馈要说清楚"怎么做"而不是"做得不对" |
| **正向激励** | "多赢小仗"（策略2） | 阶段完成时给出正向反馈 |

### 4.4 教练节奏控制

| 阶段 | 教练行为 | 频率 |
|------|---------|------|
| 探询阶段 | 中低频追问 | 每 3-4 轮检测一次 |
| 异议/推荐阶段 | 高频监控 | 每轮检测信号回应 |
| 促单阶段 | 仅在遗漏信号时介入 | 被动触发 |
| 对话结束后 | 总结评分 + 销冠对比 | 一次性 |

## 五、销冠对比设计

### 5.1 对比内容设计（基于方法论中的"最佳实践对比"）

| 对比维度 | 普通 BA 常见问题 | 销冠做法 | 方法论来源 |
|----------|----------------|---------|----------|
| **探询方式** | 直接问"你想买什么？" | "你先跟我说说你的皮肤情况，这样我能推荐最合适的" | 用户决策路径分析 |
| **异议处理** | "不会的/没事的" | "我完全理解你的担心。敏感肌用这个东西确实需要小心。我们可以..." | 动力阻力触点框架 |
| **共情话术** | 跳过共情直接说产品 | "你说怕刺痛 → 我理解，我之前也这样 → 后来发现关键是要..." | 卖点包装打动人 |
| **推荐逻辑** | 推荐最贵的 | "根据你T区油两颊干的肤质，我建议你用..." | 用户分层+卖点匹配 |
| **促单方式** | 硬推 | "你可以先拿小样回去试两天，没问题再来买正装" | 降低决策成本 |

### 5.2 对比呈现方式

根据方法论中 "好的销售在演示完之后有一个收尾动作" 的启示：

- **不单独弹报告页**，在对话流里直接展示
- 格式：先回放 BA 的原话 → 再展示销冠在同一时刻会怎么说
- 对比标注 2-3 个关键轮次，每个标注对应一个错过的信号

### 5.3 销冠回复的编写原则（源自"话术说人话"）

```
销冠回复 = 基于情景的逐字稿

要求：
1. 情景化：对应特定顾客人格和对话阶段
2. 讲人话：可以逐字念出来不别扭
3. 有路径感：知道说完这句顾客可能怎么反应
4. 带技巧标签：标出为什么这句更有效（共情/专业知识/降低决策成本）
```

## 六、评估-教练-对比的闭环逻辑

```
对话进行中：
  状态机追踪阶段 → 信号检测 → 触发主动追问/喊停

对话结束后：
  五维评分 → 关键时刻标注 → 销冠对比展示

闭环反馈：
  对比结果 → 标注正确的做法 → 提供可复用的"销冠话术"
```

**核心理念（源自科学销售）：**
> "科学销售是一个销售黑盒逐渐可视化的过程。当你用一个科学的方法拆解了销售过程，你能将过程里的节点都可视化，每个部分都是看得见的抓得着的。"

SheSells 的 Agent 就是在做这件事——将 BA 的销售对话黑盒可视化，通过状态机、评分和对比，让 BA 知道自己的每一轮对话在哪里做对了、哪里还可以提升。

## 七、Demo 场景专用方法论剪裁

由于 Demo 只做一个场景（敏感肌顾客想试早C晚A但怕翻车），以下方法论直接可用：

### 场景预设参数

| 参数 | 值 | 方法论来源 |
|------|---|----------|
| 顾客人格 | 犹豫+焦虑的敏感肌新手 | "确定用户产品"——具象化用户形象 |
| 核心需求 | 想变美（早C晚A效果好）但怕刺痛/烂脸 | 购买决策的两面性 |
| 关键信号 | "我怕刺痛"、"这个能用吗"、"万一过敏怎么办" | 异议信号 |
| 里程碑点 | 探询→共情→方案→体验 | 划分销售阶段 |
| 销冠预设 | 3段关键轮次回复 | 基于情景的逐字稿 |

### Demo 中要展示的 3 个教练行为映射

| Agent 行为 | 方法论支持 | Demo 触发时刻 |
|-----------|----------|--------------|
| **主动追问** | "实际销售中最大的问题不是做多了，而是做少了" | BA 跳过探询直接说"我推荐这款" |
| **主动喊停** | "里程碑点=用户决策成本高的点，要重点监控" | BA 连续2次没回应顾客"怕刺痛" |
| **主动对比** | "好的销售 vs 差的销售"（对比法） | 对话结束后回放关键轮次 |
